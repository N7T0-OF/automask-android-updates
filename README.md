# AutoMask — téléchargements Android

[⬇ Télécharger le dernier APK](https://github.com/N7T0-OF/automask-android-updates/releases/latest/download/AutoMask.apk) · [Notes de la dernière version](https://github.com/N7T0-OF/automask-android-updates/releases/latest)

Ce dépôt public contient uniquement les APK de distribution. Le code source reste privé.

## Installation et mises à jour

- Android 10 ou plus récent.
- Installez l’APK `AutoMask.apk` de la dernière release. Pour passer de la version 0.1.0 à 0.2.0, cette installation est nécessaire une fois : la version 0.1.0 ne possède pas encore la fonction de mise à jour.
- À partir de la version 0.2.0, AutoMask cherche une nouvelle release à l’ouverture. Le bouton **Mise à jour** permet de relancer la vérification. L’application vérifie l’empreinte SHA-256 et la signature de l’APK téléchargé avant d’ouvrir l’installateur Android.
- Android demande toujours votre accord pour installer la mise à jour et peut demander d’autoriser AutoMask comme source d’installation.

Le flou automatique des plaques repose encore sur la reconnaissance de caractères. Vérifiez toujours la vidéo avant de la partager.
